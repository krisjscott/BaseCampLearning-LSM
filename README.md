# Base Camp

Base Camp is TIES' internal, gamified learning and certification platform. It is planned as the learning layer inside Ties HQ for employees, interns, clients, and other approved audiences.

This repository is the UI-free product handoff. It contains the approved brand assets, favicon package, product scope, learner and administrator journeys, Crew ID standard, backend specification, and a static export of the Base Camp FigJam flow.

## Repository contents

- `assets/logo/` — approved Base Camp logo files
- `assets/favicon/` — ICO and PNG favicon sizes
- `docs/` — product, identity, journey, administration, and delivery documentation
- `flows/basecamp-product-flow.png` — exported FigJam board
- `backend/` — backend architecture and implementation-status documentation

## Deliberately excluded

The previous desktop UI and its Figma design are intentionally excluded. That visual direction was rejected and must not be treated as the product interface.

## Current status

The product journeys and requirements are defined. A production backend has not yet been implemented. The earlier local project only contained an empty database starter, so this repository does not present it as completed backend code.

## Source board

The editable product flow remains in [BaseCamp Flow on FigJam](https://www.figma.com/board/KJ2T6gPqiQ129xEGCjH6HT/BaseCamp--Flow).
