# Base Camp Flow

`basecamp-product-flow.png` is a static export of the approved FigJam board as of 25 July 2026.

It contains:

- 18-stage learner journey
- Email and Crew ID access
- First-time onboarding
- Course discovery, enrollment, and orientation
- Lesson, video, quiz, assignment, and progress paths
- Notifications, final assessment, completion, and certification
- Starter, Builder, Achiever, and Champion progression
- Help and exception recovery
- Admin course builder
- Admin assignment, delivery, monitoring, and certification flow

Editable source: [BaseCamp Flow on FigJam](https://www.figma.com/board/KJ2T6gPqiQ129xEGCjH6HT/BaseCamp--Flow)
