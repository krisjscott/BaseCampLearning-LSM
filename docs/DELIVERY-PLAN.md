# Delivery Plan

## Phase 0 — Decisions and governance

- Confirm product owner, learning owner, security owner, and certificate authority
- Approve authentication and identity lifecycle
- Approve course and certificate policies
- Define privacy, retention, accessibility, and reporting rules

## Phase 1 — Foundation

- Email and Crew ID authentication
- Role-based access control
- User and organization records
- Course, module, lesson, and resource model
- Admin course builder
- Assignment and enrollment
- Basic Learning Home
- Event and audit logging

## Phase 2 — Controlled learning

- Video delivery and verified watch progress
- Non-skippable configuration
- Compulsory quizzes and gating
- Assignments and reviewer workflow
- Dated progress timeline
- Reminders and deadlines
- Recovery and support states

## Phase 3 — Completion and credentials

- Completion rules engine
- Certificate templates, numbering, PDF generation, and public verification
- Accomplishments profile
- Certificate corrections, expiry, revocation, and reissue
- Admin reporting and exports

## Phase 4 — Gamification and intelligence

- XP ledger and four learning levels
- Badges and streaks
- Privacy-safe leaderboards if approved
- Recommendations and learning paths
- Course quality and assessment analytics

## Release gates

- Threat model and access-control review
- Accessibility audit
- Course-builder usability test
- Progress and completion integrity test
- Certificate verification and revocation test
- Backup, recovery, monitoring, and support runbook
- Pilot with a small internal cohort before organization-wide rollout
